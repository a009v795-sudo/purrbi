# Purrbi live-test fixtures

Real products found with Open Pet Food Facts' search, and package photos of the products whose database record lacks the label, for Purrbi's live tests. Not part of the app.

Product photos: Open Pet Food Facts contributors, CC BY-SA 3.0 (https://creativecommons.org/licenses/by-sa/3.0/); product data: Open Database License (ODbL).
Each photo's source page is listed in manifest.json.
